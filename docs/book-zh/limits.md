# 限额与订阅

限额是本地计数器，帮助你控制预算或订阅计划。Token Guard 可以限制：

- **金额**（$）
- **词元**（提示 + 补全）
- **仅输入词元**
- **仅输出词元**
- **单次请求费用**（单次请求的金额上限）
- **并发请求数**（同时处理中的请求数量）
- **请求数**（次数）
- **每分钟请求数**（速率）
- **每分钟词元数**（速率）
- **时间**（墙钟秒数）

每个限额包含：

- **周期**——一次性、每小时、每天、每周、每月、自然周/自然月或自定义秒数。（按请求计量的指标——单次请求费用、并发请求数——忽略周期：它们衡量单次请求，而非时间窗口。）
- **范围**——全局、单个服务商、单个项目或模型模式。
- **动作**——警告、阻止或暂停代理。
- 可选的**时段**——仅在特定小时和日期生效。
- 可选地加入**限额组**，让多个限额共享一个上限。

## 订阅型计划

如果你的服务商计划包含"每月 1M 词元"或"每月 $100"，请创建一个周期为**每月**、上限正确的限额。Token Guard 会在超出前发出警告或停止请求。

## 服务商式策略

服务商 API 会执行诸如"每分钟最多 60 次请求"、"最多 10 个并发请求"或"每次请求最多 200K 输出词元"之类的策略。你可以在本地复刻这些策略：

- `requests_per_minute` → 服务商允许的 RPM。
- `concurrent_requests` → 服务商的最大并发请求数。超出上限的请求会在到达服务商之前以 HTTP 429 被阻止。
- `output_tokens` → 按周期限制输出词元（例如 Gemini/Anthropic 的输出配额）。
- `cost_per_request` → 任何单次请求的费用硬上限。

## 暂停代理

动作设置为**暂停**的限额在触发时会把代理切换到暂停状态。新的请求会被拒绝，直到你从托盘图标或 Dashboard 恢复。
